プライバシーポリシー — Special Blocker for X

制定日: 2026年9月23日
最終更新日: 2026年10月28日

本ポリシーは、Chrome 拡張機能「Special Blocker for X」（以下「本拡張機能」）における情報の取り扱いを説明するものです。本拡張機能は X Corp. とは関係のない、非公式のツールです。

0. 免責

  • 本拡張機能は個人が開発したもので、X Corp. とは関係がなく、同社の承認・提携を受けたものではありません。「X」は X Corp. の商標です。
  • 本拡張機能は X の非公式の仕組みを使っており、X の仕様変更により予告なく動かなくなることがあります。
  • 短時間に多くのアカウントをブロックすると、X によりアカウントが制限・凍結される場合があります。設定と利用は利用者ご自身の判断と責任で行ってください。
  • 本拡張機能の利用によって生じた損害（アカウントの制限・凍結、誤ったブロックによる不利益を含みます）について、開発者は責任を負いません。ただし、開発者の故意または重大な過失による場合を除きます。
  • 本拡張機能は現状のまま無償で提供され、特定の目的に適合することや不具合が無いことを保証しません。

1. 概要

  • 開発者は、利用者の個人情報やデータを一切収集しません。
  • 本拡張機能の設定やログは、すべて利用者の端末内（chrome.storage.local）にのみ保存されます。
  • アクセス解析、広告、トラッキング、開発者が運営する外部サーバーは使用していません。
  • 本拡張機能が通信する相手は x.com / twitter.com のみです。

2. 端末内に保存する情報

次の情報は、利用者のブラウザ内（chrome.storage.local）にのみ保存され、開発者や第三者に送信されることはありません。

種類内容
設定各機能のON/OFF、NGワード、除外ユーザーID、巡回URL、巡回スケジュール、巡回量、1時間あたりの自動ブロック上限などの設定値
ブロック履歴ブロックした相手のユーザー名（@ID）、理由（例: 「NGワード: ○○」）、日時。直近50件と累計件数のみ
巡回履歴巡回した日時、URL、サイトごとのブロック件数などの結果。直近20件のみ
動作用の情報1時間あたりの自動ブロック数のカウント、投稿がなかったURLの一時スキップ期限、案内ページや支援バナーを表示済みかどうかの記録など

3. 保存せずに一時的に扱う情報

本拡張機能は、機能を実行するために次の情報をその場でのみ扱います。これらを保存したり、x.com / twitter.com 以外へ送信したりすることはありません。

  • 表示中のページの内容: NGワードの判定やブロック対象の特定のため、x.com 上に表示されているポストの本文・リンクURL・投稿者のユーザー名を読み取ります。
  • ログイン中のセッション: ブロックなどの操作を行うため、利用者が x.com にログインしている既存のセッション（Cookie）を使って x.com にリクエストを送ります。その際、x.com のページ上にある CSRF 対策用のトークン（ct0）を読み取り、同じ x.com へのリクエストにのみ付与します。パスワードを扱うことはありません。
  • フォロー関係: 誤ってフォロー中の相手をブロックしないよう、相手をフォローしているか・ブロック済みかを x.com に問い合わせ、結果をメモリ上に最大10分間だけ保持します。

4. 通信について

本拡張機能が行う通信は、利用者が設定・操作した機能を実行するための、x.com / twitter.com へのリクエストのみです。

  • ブロックの実行（/i/api/1.1/blocks/create.json）
  • フォロー／ブロック状況の確認（/i/api/1.1/friendships/lookup.json）
  • 巡回機能で、利用者が登録した検索結果・コミュニティのページを開くこと

これらは利用者自身のアカウントで X のサービスを利用する行為であり、X 上での情報の取り扱いには X のプライバシーポリシーが適用されます。

5. 第三者への提供

開発者は利用者のデータを受け取らないため、第三者に提供・販売・共有することはありません。本拡張機能は、利用者のデータを広告、信用力の判断、その他本拡張機能の目的と無関係な用途に使用しません。

本拡張機能による情報の利用は、Chrome Web Store ユーザーデータに関するポリシー（「Limited Use（使用の制限）」の要件を含む）に準拠しています。

6. 支援リンク（Ko-fi）

ポップアップ等にある支援リンクを押すと、拡張機能内の応援ページが新しいタブで開きます。応援ページには Ko-fi 公式の支援パネル（ko-fi.com の埋め込みウィジェット）とボタン画像が表示され、このページを開いたときに限り ko-fi.com / storage.ko-fi.com と通信します。ポップアップや X のページから Ko-fi に通信することはありません。本拡張機能から Ko-fi に利用者の情報（設定・ログ・X のアカウント情報など）を送ることはありません。支援の金額選択・お支払いは Ko-fi のパネル内で行われ、本拡張機能は支払い情報に触れません。Ko-fi 上での支援やお支払いには Ko-fi のプライバシーポリシーが適用されます。

7. 設定のエクスポート

設定のエクスポート機能を使うと、設定内容（NGワード、除外ユーザーID、巡回URLなど）を含む JSON ファイルが利用者の端末に保存されます。このファイルは利用者自身が管理するもので、本拡張機能がどこかへ送信することはありません。

8. データの削除

  • ブロック履歴は、ポップアップの「ログ」タブにある「クリア」ボタンで削除できます。
  • 本拡張機能をアンインストールすると、端末内に保存されたすべてのデータが Chrome により削除されます。

9. ポリシーの変更

本ポリシーを変更する場合は、このページを更新し、上部の「最終更新日」を改めます。データの取り扱いに重要な変更がある場合は、拡張機能の更新内容でもお知らせします。

10. お問い合わせ

Privacy Policy — Special Blocker for X

Effective date: September 23, 2026
Last updated: September 23, 2026

This policy explains how the Chrome extension "Special Blocker for X" (the "Extension") handles information. The Extension is an unofficial tool and is not affiliated with X Corp.

1. Summary

  • The developer does not collect any personal information or user data.
  • All settings and logs are stored only on your device (chrome.storage.local).
  • The Extension uses no analytics, advertising, tracking, or developer-operated servers.
  • The Extension communicates only with x.com / twitter.com.

2. Information stored on your device

The following information is stored only in your browser (chrome.storage.local) and is never sent to the developer or any third party.

TypeContents
SettingsOn/off state of each feature, NG words, whitelisted handles, patrol URLs, patrol schedule and amounts, hourly limit for automatic blocks, and similar settings
Block logHandle (@username) of each blocked account, the reason (e.g. "NG word: …"), and the time. Only the latest 50 entries and a total count
Patrol historyTime, URLs, and per-site results such as the number of blocks. Only the latest 20 runs
Operational dataThe hourly counter for automatic blocks, temporary skip periods for URLs that had no posts, and whether the onboarding page or support banner has been shown

3. Information handled temporarily and not stored

To perform its functions, the Extension handles the following information only in the moment. It is never stored, and never sent anywhere other than x.com / twitter.com.

  • Content of the page you are viewing: To match NG words and identify whom to block, the Extension reads the text, link URLs, and author handles of posts displayed on x.com.
  • Your logged-in session: To perform actions such as blocking, the Extension sends requests to x.com using your existing logged-in session (cookies). For this, it reads the CSRF token (ct0) available on the x.com page and attaches it only to requests to the same x.com. The Extension never handles your password.
  • Follow relationships: To avoid blocking accounts you follow by mistake, the Extension asks x.com whether you follow or have already blocked an account, and keeps the result in memory for up to 10 minutes.

4. Network communication

The Extension only sends requests to x.com / twitter.com in order to perform the features you have configured or triggered:

  • Blocking an account (/i/api/1.1/blocks/create.json)
  • Checking follow/block status (/i/api/1.1/friendships/lookup.json)
  • Opening the search or community pages you registered, during a patrol

These requests are made with your own account on X's service, and X's privacy policy applies to how information is handled on X.

5. Sharing with third parties

Because the developer receives none of your data, it is never provided, sold, or shared with third parties. The Extension does not use your data for advertising, for determining creditworthiness, or for any purpose unrelated to the Extension's single purpose.

The use of information by the Extension complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

6. Support link (Ko-fi)

Clicking the support link (for example, in the popup) opens the Extension's own support page in a new tab. That page shows Ko-fi's official tip panel (an embedded ko-fi.com widget) and button image, so it connects to ko-fi.com / storage.ko-fi.com only while that page is open. The popup and X pages never contact Ko-fi. The Extension does not send any of your information (settings, logs, X account details, etc.) to Ko-fi. Choosing an amount and paying happen inside Ko-fi's panel; the Extension never touches payment details. Ko-fi's privacy policy applies to any support or payment you make on Ko-fi.

7. Settings export

When you use the settings export feature, a JSON file containing your settings (NG words, whitelisted handles, patrol URLs, etc.) is saved to your device. You control this file; the Extension does not send it anywhere.

8. Deleting your data

  • You can delete the block log with the "Clear" button on the "Log" tab of the popup.
  • Uninstalling the Extension causes Chrome to delete all data the Extension stored on your device.

9. Changes to this policy

If this policy changes, this page will be updated and the "Last updated" date above will be revised. Significant changes to data handling will also be noted in the Extension's release notes.
